# 🧾 পারিবারিক হিসাব ও কাপড় ব্যবসা

সম্পূর্ণ **বাংলা ভাষার** পারিবারিক আয়-ব্যয় ও কাপড় ব্যবসা ম্যানেজমেন্ট ওয়েব অ্যাপ।
সব মুদ্রা **বাংলাদেশি টাকা (৳)** — সংখ্যাগুলো বাংলায় দেখায়।

## পরিবারের সদস্য (৬ জন) ও ভূমিকা

| নাম | ভূমিকা | কী করতে পারবেন |
|---|---|---|
| **প্রিয়া** | সদস্য | নিজের খরচ যোগ, সব তথ্য দেখা, নিজের রসিদ |
| **মৌন** | সদস্য | নিজের খরচ যোগ, সব তথ্য দেখা, নিজের রসিদ |
| **মারুফ** | আয়দাতা (ভাই) | পরিবারে **আয় যোগ**, নিজের খরচ, সব দেখা |
| **মিনু** | সদস্য | নিজের খরচ যোগ, সব তথ্য দেখা, নিজের রসিদ |
| **সাখাওয়াত** | ব্যবসায়ী (বাবা) | **কাপড় ব্যবসার সব ডেটা** (স্টক/বিক্রি/ক্রয়/বাকি-দেনা), নিজের খরচ |
| **তিতলী** | সদস্য | নিজের খরচ যোগ, সব তথ্য দেখা, নিজের রসিদ |
| **অ্যাডমিন** | প্রশাসক | সবকিছু + যেকোনো সদস্যের রসিদ তৈরি |

## চালু করার নিয়ম

```bash
cd /root/family-finance-app
npm install
npm start          # অথবা: node server.js
```

ব্রাউজারে খুলুন: **http://localhost:8000** (একই নেটওয়ার্কের অন্য ফোন/কম্পিউটার থেকে: `http://<এই-কম্পিউটারের-IP>:8000`)

- সব সদস্যের পিন: **১২৩৪**
- অ্যাডমিনের পিন: **১২১২**

## ফিচার

- 🔐 প্রত্যেক সদস্যের আলাদা লগইন (নাম বেছে পিন)
- ⚡ **রিয়েল-টাইম আপডেট** (Socket.IO) — কেউ কিছু বদলালে সবার স্ক্রিনে সাথে সাথে দেখায়
- 💰 আয়-ব্যয়: খাত (খাবার, বাড়ি ভাড়া, বিদ্যুৎ, গ্যাস, পড়াশোনা, চিকিৎসা, যাতায়াত, অন্যান্য), তারিখ, নোট, কে যোগ করল
- 🏪 ব্যবসা: কাপড়ের নাম/পরিমাণ/ক্রয়-বিক্রয়মূল্য; **বিক্রি করলে স্টক কমে, ক্রয় করলে স্টক বাড়ে** (স্বয়ংক্রিয়)
- 📒 বাকি/দেনা: পাওনা ও দেনা আলাদা, পরিশোধিত/বাকি স্ট্যাটাস
- 🧾 ব্যক্তিগত রসিদ: তারিখ-সীমা সহ জমা/খরচ/নিট ব্যালেন্স — **প্রিন্ট ও ডাউনলোড**
- 📊 মাসিক ও বার্ষিক রিপোর্ট (খাতভিত্তিক খরচ, সদস্যভিত্তিক আয়-খরচ, ব্যবসার লাভ)
- 🗑️ কিছু মুছতে চাইলে আগে **নিশ্চিতকরণ** জিজ্ঞেস করে
- 📱 মোবাইল ও কম্পিউটার — দুটোতেই সুন্দর দেখায়

## প্রযুক্তি

- **ব্যাকএন্ড:** Node.js + Express + Socket.IO (রিয়েল-টাইম)
- **ডেটাবেস:** `data/db.json` ফাইলে সব ডেটা সংরক্ষিত (ব্যাকআপ নিতে শুধু এই ফাইলটি কপি করুন)
- **ফ্রন্টএন্ড:** খাঁটি HTML/CSS/JavaScript, Hind Siliguri ফন্ট
- **নিরাপত্তা:** পিন scrypt দিয়ে হ্যাশ করা, httpOnly সেশন কুকি

## ফাইল কাঠামো

| ফাইল | কাজ |
|---|---|
| `server.js` | API সার্ভার, পারমিশন, হিসাব, রিয়েল-টাইম |
| `public/index.html` | অ্যাপের কাঠামো |
| `public/style.css` | ডিজাইন (বাংলা ফন্ট, প্রিন্ট স্টাইল) |
| `public/app.js` | সব স্ক্রিন ও লজিক |
| `data/db.json` | সব ডেটা (প্রথম চালুতে নমুনা ডেটা তৈরি হয়) |

> 💡 নতুন করে শুরু করতে চাইলে `data/db.json` মুছে সার্ভার চালু করুন — নমুনা ডেটাসহ নতুন ডেটাবেস তৈরি হবে।
